Existing services stay authoritative. Shared shell/design system and facade only if required via ADR; no monolithic backend rewrite or duplicated execution engine. AI Architect generic solution design service/orchestration layer calls authorized resources and drafts using validated schema/explicit human save, no unchecked model writes. Project registry mapping canonical IDs; choose owning service with ADR (CP or small project service) avoiding duplicate state. New economics service/ledger may be module or separate service; decide storage and tenant authority, integrate measured telemetry via event contract not scraper. Generic connector registry/adapter execution security and runtime support are new; first wire existing approved adapters. Business app definition/domain packs act as reusable contract; generate prebuilt schema-driven views, not arbitrary AI-generated executable app code without review. Native multi-model adapter list and compatibility verified by probes; no claims for untested provider. External n8n import compatibility only via explicit mappings, no n8n runtime embedding; licensing check separately. Preserve current API paths, test old clients, version new endpoints. No external production credentials or customer access by default.
