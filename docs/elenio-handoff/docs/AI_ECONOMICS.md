# AI Economics — functional and technical specification

## Objective and UX
Enterprise must decide whether agentic workflow is worth doing versus conventional process. Economics is a first-class product capability with a global portfolio view AND contextual project/architect/node/test/run/deploy views. Do not substitute token dashboard for full unit economics. Elenio engineers estimate before selling, IT measures during validation, Finance/business owners audit actual cost and outcome post-release. Show three clearly separate modes: **estimated scenario**, **measured sandbox**, **actual production**; no fabricated values. All sample numbers strictly labelled synthetic, editable and separated from production. No live price claim without approved rate card. Show currency, effective date, assumptions, environment, time window, model/version, quality/cost benchmark conditions, and missing telemetry/estimated coverage. Business benefit not guaranteed; separate cash savings and capacity released.

## Inputs and entities (proposed schema; ADR before implementation)
- `RateCardVersion`: tenant/scope, provider/model deployment, currency, effective_from/to, input/output/cache read/write token unit prices, embedding/OCR/requests/image/compute/GPU unit rate if applicable, source and author approval. Rate override/version history, no retroactive change of settled ledger unless adjustment event. Use decimal/integer minor unit arithmetic with explicit units; FX rate snapshot with date/source for reporting currency. Unknown rate = unpriced, never zero. Zero explicitly allowed for no incremental charge; full allocation separate.
- `CostScenario`: project/definition version, monthly attempted cases, completed/acceptance rate, branch probability conditional on reach, loop/attempt/retry assumptions, token estimates per call and model version, tool calls, review probability and time, operator loaded cost/hour, fixed monthly license/runtime/maintenance/monitoring/storage/GPU, implementation capex, amortization horizon/months, conventional labor minutes/wage, conventional tool cost, conventional fixed overhead, baseline throughput/quality/SLA/exception rate, chosen assumptions provenance. Validate numbers/ranges; avoid negative volume/cost/rates, branch probabilities sum to one per exclusive decision, parallel branches each execute when reached. Reject unsupported cycles/unbounded expectations.
- `ExecutionUsageEvent`: stable event id and idempotency key, tenant/workspace/project/workflow/version/run/case/node/agent/skill/model deployment/version, attempt id, event timestamp, environment, status, actual input/output/cached tokens, tool invocations, compute seconds, units, data source, correlation id, completeness; no secrets or raw prompt by default. Capture all attempts, failures, cancellation, retries, errors. Agent runtime token telemetry currently documented; actual integration and per-attempt coverage must be verified. Service adapter cost events, OCR, embedding, storage and GPU allocation from approved sources. Human review time captured or estimated with correct label. Dedup by stable usage identity, distinguish repeated legitimate attempts. Late arrival and correction via append-only adjustment. Authorized rollups only; tenant isolation and auditable changes.
- `BudgetPolicy`: per run, workflow, project, workspace/month limits, warning vs hard cap, model allowlist, max calls/retries, authorized override with audit; estimate cannot guarantee final charge. Preflight projected usage and atomic reservation where applicable, settle actual after provider response; handle concurrency and partial usage. Hard stop must not strand irreversible action or bypass approvals: safe pause/review, no hidden fallback. Warn-only initially if reliable enforcement missing; label unsupported.

## Formula requirements
Use consistent currency, time horizon, volume and success rate across manual and AI. Rate for tokens generally per million: `model_cost = input_uncached_tokens/1e6*input_rate + output_tokens/1e6*output_rate + cache_read_tokens/1e6*cache_read_rate + cache_write_tokens/1e6*cache_write_rate + other billable units * corresponding rates`. Provider usage semantics differ; do not double count cached tokens included in input; normalize adapter usage with provenance.

Machine variable expected cost per attempted workflow = sum over each reachable node of E[visits/attempts] × marginal cost per visit (including model, external tools/API, embedding/OCR, variable compute and storage as applicable). `E[visits]` respects actual DAG, conditional reach probabilities, repeated executions, parallel paths and join executes once per reached case; don't sum all alternative branches, don't multiply independent-looking conditions if correlated. Model retry expectation use explicit expected attempts or bounded retry distribution; no infinite loops. For complex graphs use validated path enumeration or dynamic programming with documented assumptions; mark approximation if correlations unsupported. Budget/quality checks on worst-case and scenario range when feasible, not expected cost alone.

`V` attempted volume/month; `Q` completed acceptable cases/month; `v_ai` per-attempt variable machine + human review/rework labor + other incremental cost; `F_ai` fixed monthly AI overhead; `I` one-time implementation; `N` useful amortization months. Conventional equivalent `v_conv`, `F_conv`, `Q_conv` for same workload and quality; manual baseline e.g. minutes × loaded hourly cost/60 + per-case tools. `Operating AI monthly = V*v_ai + F_ai`. `Fully allocated AI monthly = operating + I/N` when chosen, show separately. `Operating conventional monthly = V*v_conv + F_conv`. `Cost/attempt = fully allocated / V`; `cost/acceptable completed case = total / Q`. Undefined for zero denom; show N/A, not infinity or misleading zero. Failure costs stay numerator. Compare like-for-like output and volume; if quality differs, surface difference, do not equate to saved cash. `Monthly operating difference = conv operating − ai operating`. `Monthly full-cost difference = conv operating − ai fully allocated`. `Reduction % = (baseline−AI)/baseline` nonzero baseline. Simple break-even V = `(F_ai + I/N − F_conv)/(v_conv − v_ai)` for positive denominator, round up and floor at zero; if denominator <=0 handle no/conditional break-even (AI fixed advantage may favor low volume; show curves, not incorrect no-break-even). `Payback months = I / positive monthly operating difference`; not reached if <=0. `H-month AI TCO = I + H*operating monthly` (or monthly schedule); conventional TCO includes relevant one-time costs, do not double count amortization and capex. `ROI over H = (conventional TCO − AI TCO) / AI TCO` for cost-based ROI, explicitly label formula; separately if verified monetized incremental benefits included and no double count. If using incremental-investment ROI, label alternative formula and denominator/NPV assumptions; never mix. Human time saved vs eliminated spend distinct. Sensitivity for volume, quality, branch, rates, GPU utilization, salary, implementation, fixed overhead. Model optimization only after quality/safety/privacy/latency thresholds, choose lowest compliant cost; no automatic model switch without policy/release approval.

## Concrete synthetic fixture for deterministic unit tests
Vendor workflow: extraction agent Rp250, ERP lookup Rp200, exception agent Rp600 only unmatched (p=.25), policy step Rp150, ERP posting Rp300 on all approved fixture cases, trigger/approval machine charge 0. Expected machine = 250+200+.25*600+150+300 = Rp1,050. Matched path Rp900; unmatched Rp1,500. (All cases approved in fixture; rejection scenario separate and posting not reached.) Include human review Rp1,500 per case, fixed OPEX Rp2,000,000/month, one-time implementation Rp12,000,000 amortized 12 months; conventional Rp12,000/case and fixed 0. V=1,000, Q=1,000. Expected variable Rp2,550; operating monthly Rp4,550,000; amortized monthly Rp5,550,000; cost/attempt and completed Rp5,550; conventional Rp12,000,000; monthly operating difference Rp7,450,000, full cost difference Rp6,450,000; full cost reduction 53.75%; simple break-even ceil(3,000,000/9,450)=318 cases/mo; payback ~1.61 months; 12mo TCO Rp66,600,000 vs Rp144,000,000; cost-based ROI (144−66.6)/66.6 ~116.22%. No external pricing assumptions, not actual savings. Validate p=0/p=1 changes cost; if posting denied, don't charge posting; a failed/retried run still costs prior attempts. Test parallel branches both run, join once; missing rates; zero volume/zero successes; negative savings; FX effective dates; duplicate events; budget overshoot/parallel reservations; unauthorized tenant; rejected release; model comparison with critical failure despite high mean score. Model comparison fixtures strictly sandbox, not claims about actual vendors.

## UI views and acceptance
Architect estimate with assumptions/uncertainty and suggested model strategy. Canvas inspector cost by node, branch labels/expected probability and cost path. Model Hub editable approved rate cards, version/effective dates; provider capability probe consent. Testing measured run cost, actual token breakdown on same dataset, trace input/output and evidence, quality-latency-cost comparison with privacy filter and critical gate. Global Economics project portfolio: filters by date/workspace/env, actual vs plan, cost per acceptable case, cost drivers and budget alerts, baseline vs agentic TCO and break-even curve; display completeness. Operations run detail cost by attempt/node/model/connector, link actual trace. Deployment cost baseline and budget policy included in review; version pin. Customer self-hosted compute allocation (GPU amortization/utilization, electricity/hosting/storage/maintenance) not zero, clarify marginal vs fully loaded. Expose CSV/report with sources/assumptions and authorization. All data and charts trace to ledger or explicit scenario values. Use tests for formulas and E2E input/model/branch changes; no simulated numbers promoted into actual telemetry. Persist scenario versions and approved decisions; cost schema changes backwards compatible. Finance sign-off on baseline and interpretation before claiming economic ROI.
