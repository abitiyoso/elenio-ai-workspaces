## How to use (local Codex)
1. Extract this ZIP into a separate working folder, e.g. `D:\Elenio\Elenio_Codex_Development_Kit` (not inside the team's source repo). Open Codex from that folder with Git/terminal access and GitHub authenticated as your account. Keep local references private. You can use the standalone `MASTER_PROMPT.md` if downloaded separately, but full kit is recommended for visuals and source PRD.
2. Paste the short starter below, or paste `MASTER_PROMPT.md` directly. Codex reads the file and handles safe clone/private origin, then Phase 0 & Phase 1. Proposed repo `abitiyoso/elenio-ai-workspaces`; if you prefer another owner/name, edit that before running. Source repo is `kawakibireku/ai-workspace`; never write there.
3. Review screenshots, workflow and Knowledge Hub in Phase 1. Approve/revise visual gate before invoking Phase 2+ prompts from `docs/PHASES_ACCEPTANCE.md`. Development commits always pushed to feature branch in YOUR repo, main merged only with approval. The original code remains read-only. No production deployments automatically.
